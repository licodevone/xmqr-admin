Como interpretar esta leitura

São agregados reais, sem nomes, tópicos ou conteúdo das mensagens. “Pronto” indica que o ator e o armazenamento responderam ao monitor; não garante espaço em disco nem processamento pelos dispositivos.

Operações pelo terminal

Os comandos abaixo já existem neste software. Nesta versão, o painel não altera arquivos nem executa operações administrativas.

Usuários de laboratório

Criar, listar, alterar senha e excluir. As senhas são solicitadas sem aparecer no terminal. Alterações nos arquivos legados exigem reiniciar o broker.

xmqr-admin user list --users-file ARQUIVO
xmqr-admin user create --users-file ARQUIVO --username USUARIO
xmqr-admin user update-password --users-file ARQUIVO --username USUARIO
xmqr-admin user delete --users-file ARQUIVO --username USUARIO

Backup e recuperação

Pare o broker antes do backup. Verifique a cópia antes de restaurar; a restauração cria um diretório novo e não substitui o estado ativo.

xmqr-admin state backup --state-dir DIR --destination NOVO_DIR
xmqr-admin state verify --backup DIR_BACKUP
xmqr-admin state restore --backup DIR_BACKUP --state-dir NOVO_DIR

Preparação da segurança

Gerar hash de senha e identificar um certificado. Esses comandos não emitem certificados nem gerenciam a configuração dinâmica.

xmqr-admin hash-password
xmqr-admin fingerprint CERTIFICADO.crt

Uma ferramenta, três responsabilidades

Broker recebe conexões, aplica permissões e distribui mensagens.

Admin prepara arquivos e backups; este painel observa agregados.

Client publica e recebe mensagens MQTT, inclusive nos dispositivos ESP32.

Próximos incrementos — ainda não implementados

  • Gestão de grupos, papéis e permissões do modo seguro.
  • Canal administrativo autenticado para operações ao vivo.
  • Detalhamento de clientes, desconexão e administração de sessões/retained.
  • Auditoria e gestão pelo painel após validação desse canal.

Versão experimental. Não exponha este painel ou o monitor do broker na rede local ou na internet. O binário mqtt-admin legado continua disponível, com versão do broker.
