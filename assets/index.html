Operações administrativas

Operações disponíveis pelo terminal. O painel não executa estes comandos.

Usuários de laboratório

Criar, listar, alterar senha e excluir. As senhas são solicitadas sem aparecer no terminal. Alterações nos arquivos legados exigem reiniciar o broker.

xmqr-admin user list --users-file ARQUIVO
xmqr-admin user create --users-file ARQUIVO --username USUARIO
xmqr-admin user update-password --users-file ARQUIVO --username USUARIO
xmqr-admin user delete --users-file ARQUIVO --username USUARIO

Backup e recuperação

Pare o broker antes do backup. Verifique a cópia antes de restaurar. A restauração cria um diretório novo.

xmqr-admin state backup --state-dir DIR --destination NOVO_DIR
xmqr-admin state verify --backup DIR_BACKUP
xmqr-admin state restore --backup DIR_BACKUP --state-dir NOVO_DIR

Preparação da segurança

Gerar hash de senha e identificar um certificado. Esses comandos não emitem certificados.

xmqr-admin hash-password
xmqr-admin fingerprint CERTIFICADO.crt

Configuração e acesso

Os endereços e as credenciais são preparados no servidor.

Três softwares, um fluxo

Broker recebe conexões e distribui mensagens conforme as permissões.

Client publica e assina tópicos. O console usa o client instalado no servidor.

Admin mostra o monitor e oferece este console autenticado.

Habilitar o Console MQTT

Prepare perfis privados do mqtt-client com o broker, TLS e credenciais autorizadas. Configure estes caminhos ao iniciar o admin:

XMQR_ADMIN_MQTT_CLIENT_BIN=/usr/bin/mqtt-client
XMQR_ADMIN_MQTT_SUB_PROFILE=/caminho/privado/assinatura.toml
XMQR_ADMIN_MQTT_PUB_PROFILE=/caminho/privado/publicacao.toml
XMQR_ADMIN_MQTT_LABEL=Broker local
xmqr-admin serve

Os nomes acima são variáveis de ambiente; exporte-as no terminal antes de executar o admin. Use arquivos regulares com permissão 0600 no Linux. Se o perfil de publicação for omitido, será usado o de assinatura. Senhas e configurações privadas não são enviadas ao navegador.

Mantenha o painel e o monitor em loopback. Uma assinatura é compartilhada pelo painel local. Sair encerra essa assinatura; fechar a página solicita seu encerramento, e o servidor também aplica um prazo sem consultas.
