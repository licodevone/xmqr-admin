# XMQR Admin 0.8.0 — compatibilidade com estado v13 (experimental)

O core Git está fixado no commit exato `0254a55659b2bdcb02d0abae6057d457e6a49bcf` da tag broker `v0.26.0`. O admin independente valida bundle e faz backup/verify/restore offline do documento v13, preservando associação compartilhada persistente, Subscription Identifier e entrega QoS2 da sessão escolhida. O canal local e o painel autenticado de leitura permanecem.

**Estado e rollback:** pare o broker antes do backup/restauração. O backup não contém `.mqtt-broker-profile`; escolha e confira o perfil de listener separadamente antes de reabrir o estado restaurado. Broker 0.25.0 e admin independente 0.7.0 não abrem v13. Para voltar à família anterior, preserve antes da migração um backup privado v12, pare o broker, restaure esse backup e reinstale as versões antigas. Downgrade de pacote não converte estado.

**Limites:** pacote Ubuntu 26.04 amd64 e imagem Debian Bookworm linux/amd64; testes e conferência remota em andamento. Painel de escrita, Windows nativo, arm64, Ubuntu 24.04, acesso remoto e alegação de produção seguem fora do aceite. Docker `latest` permanece intacta; o processo de release não altera a WSL do operador.
