# XMQR Admin 0.10.0 — compatibilidade com estado v15 (experimental)

A19 fixa o core do broker 0.29.0/P164 no commit `9215d4c1e6fb59f3ab73d684ecfbaf9ed38e72b2`. Backup, verificação e restauração offline preservam um Will MQTT 5 pendente com Message Expiry Interval. O painel permanece somente leitura e o perfil do listener continua externo ao backup.

**Compatibilidade:** o admin 0.9.0 também consegue transportar um backup bruto v15 sem ler o documento MQTT; isso não homologa a combinação com broker novo. Broker 0.28.0 rejeitou v15 no ensaio descartável. Para voltar a essa versão, pare o serviço e restaure backup privado v14 anterior à primeira gravação v15.

**Distribuição:** tag anotada, prerelease, pacote Ubuntu 26.04 amd64, imagem numerada e manifestos após CI do commit exato, rollback descartável e conferência de SHA-256/digest. [A20](../../prompts/registros/A20-release-0.10.0.md) registrará hashes. WSL do operador e Docker `latest` não são alterados.
