# XMQR Admin 0.7.0 — compatibilidade com estado v12 (experimental)

O core Git está fixado no commit exato `6462b83858ea5ca57bf13c6e83efa74e4523c637` da tag broker `v0.25.0`. O admin independente valida bundle e faz backup/verify/restore offline do documento v12, incluindo os Subscription Identifiers por assinatura. O canal local e o painel autenticado de leitura permanecem.

**Estado e rollback:** pare o broker antes do backup/restauração. O backup não contém `.mqtt-broker-profile`; escolha e confira o perfil de listener separadamente antes de reabrir o estado restaurado. Broker 0.24.0 e admin independente 0.6.0 não abrem v12. Para voltar à família anterior, preserve antes da migração um backup privado v11, pare o broker, restaure esse backup e reinstale as versões antigas. Downgrade de pacote não converte estado.

**Limites:** CI do commit exato, pacote Ubuntu 26.04 amd64, imagem Debian Bookworm linux/amd64 e conferência remota passaram. Painel de escrita, Windows nativo, arm64, Ubuntu 24.04, acesso remoto e alegação de produção seguem fora do aceite. Docker `latest` fica intacta; o processo de release não altera a WSL do operador.
