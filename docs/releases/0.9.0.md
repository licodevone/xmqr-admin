# XMQR Admin 0.9.0 — compatibilidade com estado v14 (experimental)

O core Git está fixado no commit exato `53d86a7e296c158d9247bc5011dec1da49c39b29` do broker 0.27.0. O admin independente valida bundle e faz backup/verify/restore offline do documento v14, preservando origem da cópia QoS1 compartilhada, identificador de assinatura e obrigação redistribuída. Canal local e painel autenticado somente leitura permanecem.

**Estado e rollback:** pare o broker antes do backup/restauração. O backup não contém `.mqtt-broker-profile`; confira o perfil de listener separadamente ao restaurar. Broker 0.26.0 e admin 0.8.0 não abrem v14. Para voltar, restaure backup privado v13 feito antes da primeira gravação nova; downgrade de pacote sozinho não converte estado.

**Distribuição e limites:** CI, pacote Ubuntu 26.04 amd64, imagem numerada, ciclo de rollback e hashes remotos pendentes. Painel de escrita, Windows nativo, arm64, Ubuntu 24.04 e conformidade MQTT 5 integral seguem fora deste marco. Não mover Docker `latest` nem instalar no WSL do operador.
