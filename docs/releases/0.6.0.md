# XMQR Admin 0.6.0 — compatibilidade com estado v11 (experimental)

O core Git está fixado no commit exato `8dde5fda09935fe9d72b3524fe898da39f6bb6f1` da tag broker `v0.24.0`. O admin independente valida bundle e faz backup/verify/restore offline do documento v11, incluindo opções No Local e Retain As Published por assinatura. O canal local e o painel autenticado de leitura permanecem.

**Estado e rollback:** pare o broker antes do backup/restauração. O backup não contém `.mqtt-broker-profile`; escolha e confira o perfil de listener separadamente antes de reabrir o estado restaurado. Broker 0.23.0 e admin 0.5.0 não abrem v11. Para voltar à família anterior, preserve antes da migração um backup privado v10, pare o broker, restaure esse backup e reinstale as versões antigas. Downgrade de pacote não converte o estado.

**Limites:** pacote Ubuntu 26.04 amd64 e imagem Debian Bookworm linux/amd64. Painel de escrita, Windows nativo, arm64, Ubuntu 24.04, acesso remoto e alegação de produção seguem fora do aceite. Docker `latest` fica intacta. Confira SHA-256 e manifesto antes de instalar; o processo de release não altera a WSL do operador.
